# Answer Sheet Scanner

A Python project to scan and grade multiple-choice answer sheets using image processing and OpenCV.

## Features

- Automatically detects and extracts index numbers.
- Reads marked answer bubbles (A–E).
- Grades responses against an answer key.
- Outputs a performance summary.

## Requirements

- Python 3.x
- OpenCV
- numpy
- matplotlib (optional for visualization)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/answer-sheet-scanner.git
cd answer-sheet-scanner
```
